# Security Policy

## Supported Versions

| Version | Status |
|---|---|
| Latest tagged release | Security fixes |
| `main` | Development snapshots; fixes land here first |
| Older releases | Upgrade to the latest release |

## Reporting a Vulnerability

Please report suspected vulnerabilities in the LabTether CLI privately:

- [Report a vulnerability](https://github.com/labtether/labtether-cli/security/advisories/new)
  through GitHub private vulnerability reporting, or
- email [support@labtether.com](mailto:support@labtether.com) with "Security" in the subject.

Do not open a public issue, discussion or pull request for an undisclosed
vulnerability.

Include:

- the affected version or commit, your operating system and architecture, and the Hub version
- the impact and the steps to reproduce it
- logs or screenshots with tokens, API keys and other secrets removed

We aim to acknowledge reports within 5 business days. We prefer coordinated
disclosure: please keep details private until a fix or mitigation is released
or a disclosure date has been agreed.

Issues in the Hub, agents or other LabTether components can be reported the
same way; see the [Hub security policy](https://github.com/labtether/labtether/security/policy).

## Questions and Ordinary Bugs

Use [GitHub Discussions](https://github.com/labtether/labtether/discussions)
for questions and [issues](https://github.com/labtether/labtether-cli/issues) for
bugs that are not security sensitive.
